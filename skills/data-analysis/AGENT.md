# Trusted Procurement Agent

매일 아침 6시(Asia/Seoul), **사람이 없어도 혼자 돈다.**

## 하는 일

```
오늘 시세 조회 (호출 1회)
   └ 어제와 같으면 → 여기서 끝
   └ 다르면 ↓
수집 → 판정 → 어제와 비교 → 화면
```

## 🔴 예약 실행에서 지켜야 할 것

**① 아무것도 묻지 않는다**

인증키가 없으면 **동봉 스냅샷으로 진행한다.** `request_env_var` 를 부르면
예약 실행이 사람 응답을 기다리며 멈춘다 — 그 순간 Agent 가 아니게 된다.

키 등록은 **사람이 대화로 부를 때만** 한다([SKILL.md](SKILL.md) 「준비」 절).

**② 데이터는 워크스페이스 루트 아래에 쓴다**

`.pi/skills/` 는 매 턴 라이브러리에서 다시 만들어진다. `TPA_DATA_DIR=./tpa` 를
설정해야 `./tpa/state/last_run.json` 이 살아남아 **「어제와 같은가」를 판정**할 수 있다.

**③ 변화가 없으면 아무것도 만들지 않는다**

같은 화면을 매일 다시 그리면 사람이 읽지 않게 된다.

**④ 「이월분 재개」도 새 산출물이다**

실패했다가 회복한 주기는 **새로운 판정을 낸 것**이다. 화면을 띄운다.
이 분기를 빠뜨리면 사용자는 회복 사실을 모른다.

**⑤ 숫자를 만들지 않는다**

`report.json` 에 있는 값만 옮긴다. 응답에 쓸 문장이 필요하면
`agent.py` 출력의 「↳」 줄을 그대로 쓴다.

## 사람이 부를 때 (대화형)

- 인증키를 처음 넣을 때 — `request_env_var` 로 `DATAGO_KEY` 요청
- 취급 품목을 고를 때 — `create_spreadsheet` 로 `reference/item_map.csv` 를 띄움

**둘 다 선택이지 실행 조건이 아니다.** 하지 않아도 예약 실행은 계속 돈다.
