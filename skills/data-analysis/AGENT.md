## 🔴 이 파일을 **그대로** 쓴다 — 새로 쓰지 않는다

    name             trusted-procurement-agent   스킬과 이름을 맞춘다
    model            solar-open2                 대회가 지정한 모델
    schedule         0 6 * * *                   매일 아침 6시 (Asia/Seoul)
    trigger_prompt   파일에 있는 그대로           안전장치가 들어 있다

실제로 이것을 새로 쓴 적이 있다. 그때 이름이 `daily-procurement-briefing`
으로 바뀌었고, `model` 이 `claude-haiku-4-5` 가 됐고, 스케줄이 비었고,
**요약 금지·품목명 변경 금지가 통째로 빠져** 품목 이름이 날조된 표가 나왔다.

플랫폼이 요구하는 키가 더 있으면 **그것만 더한다.** 위 네 값은 그대로 둔다.

## 🔴 이 파일을 어디에 두어야 하나

타임리는 **에이전트를 `.pi/agents/<이름>/AGENT.md` 에서 읽는다.**
스킬 zip 은 `.pi/skills/` 아래에 풀리므로, **이 파일은 그 자리에 있는 한
에이전트 정의로 읽히지 않는다.** 실제로 그래서 모델이 자기 AGENT.md 를
새로 썼고, 여기 적힌 안전장치(요약 금지·품목명 변경 금지)가 통째로
빠진 채 돌았다.

그래서 **zip 이 두 자리에 같은 파일을 담는다** — 올리면 이미 제자리다.

    .pi/skills/trusted-procurement-agent/AGENT.md   (스킬 안 사본)
    .pi/agents/trusted-procurement-agent/AGENT.md   ← 타임리가 읽는 자리

플랫폼이 스킬 zip 에서 `.pi/agents/` 를 풀지 않는다면, **스킬을 등록하는
같은 턴에** 위 복사를 한다 — [SKILL.md](SKILL.md) 맨 앞 「이 스킬이 등록될
때」 절에 그렇게 적어 두었다. 사람이 따로 시키지 않아도 된다.

## 🔴 예약 실행에서 지켜야 할 것

**① 아무것도 묻지 않는다**

인증키가 없으면 **동봉 스냅샷으로 진행한다.** `request_env_var` 를 부르면
예약 실행이 사람 응답을 기다리며 멈춘다 — 그 순간 Agent 가 아니게 된다.

키 등록은 **사람이 대화로 부를 때만** 한다([SKILL.md](SKILL.md) 「준비」 절).

**② 데이터는 워크스페이스 루트 아래에 쓴다**

`.pi/skills/` 는 매 턴 라이브러리에서 다시 만들어진다. `TPA_DATA_DIR=./tpa` 를
설정해야 `./tpa/state/last_run.json` 이 살아남아 **「어제와 같은가」를 판정**할 수 있다.

**③ 변화가 없으면 수집도 판정도 하지 않는다**

지문이 같으면 **API 호출 1회로 끝난다.** 수집·판정·렌더링을 전부 건너뛴다.
한 주기의 최소 비용이 여기서 정해진다.

🔴 **화면을 다시 만들지 말라고도 적어 두었지만, 그것은 보장하지 못한다.**
   실측에서 모델이 「변화 없음」을 정확히 보고하고도 아티팩트를 다시
   만들었다. 프롬프트의 금지가 「도움이 되려는」 기본 행동을 못 이긴다.

   그래서 **주장을 좁힌다.** 이 스킬이 보장하는 것은 「같은 자료면 다시
   계산하지 않는다」이지 「화면이 안 뜬다」가 아니다. 증거는 화면 유무가
   아니라 출력의 **「변화 없음 — 건너뜀 · 호출 0」** 한 줄이다.

**④ 「이월분 재개」도 새 산출물이다**

실패했다가 회복한 주기는 **새로운 판정을 낸 것**이다. 화면을 띄운다.
이 분기를 빠뜨리면 사용자는 회복 사실을 모른다.

**⑤ 숫자를 만들지 않는다**

`report.json` 에 있는 값만 옮긴다. 응답에 쓸 문장이 필요하면
`agent.py` 출력의 「↳」 줄을 그대로 쓴다.

## 사람이 부를 때 (대화형)

- 인증키를 처음 넣을 때 — `request_env_var` 로 `DATAGO_KEY` 요청
- 취급 품목을 고를 때 — `create_spreadsheet` 로 `reference/item_map.csv` 를 띄움

**둘 다 선택이지 실행 조건이 아니다.** 하지 않아도 예약 실행은 계속 돈다.
